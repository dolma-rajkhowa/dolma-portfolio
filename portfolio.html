Alienkind: Concept Deck

Concept Definition: Continuing the established alien invasion lore, this project reframes the brand through a biological lens. It utilizes TouchDesigner generative feedback loops to simulate organic, bio-scopic textures. These visual assets act as leaked clinical research files, systematically positioning the product as a biological upgrade rather than a standard consumer commodity. The integration of glitch aesthetics and fluid simulations creates a symbiotic texture representing living data.

AQI Visualiser

Technical Logic: A functional, real-time environmental data visualizer engineered in TouchDesigner. This system fetches live parameters from a free AQI API to mathematically control generative feedback switches. It dynamically shifts visual states across safe (green), moderate (blue), and hazardous (red) thresholds based on localized data inputs. The underlying node architecture is highly modular, with the statistical potential to be adapted for localized weather mapping, humidity sensors, or time-of-day parameter shifting.
